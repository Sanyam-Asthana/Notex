# Notex

Notex is a classless CSS framework, which gives minimalist and elegant styling to semantic HTML.

## Usage

Notex can be included via CDN by adding the following line in the HTML header:

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/Sanyam-Asthana/Notex@main/notex.css">
```

It can also be included as a standalone stylesheet, but it needs to be present in the current directory:

```html
<link rel="stylesheet" href="notex.css">

```
